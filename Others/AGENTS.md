# Others Agent Instructions

## 적용 범위

- 이 파일은 VSCode 루트 기준 `./Others` 아래의 독립 도구·실험·로컬 AI 작업에 적용합니다.
- 루트 `AGENTS.md`와 `Agents/workflow.md`를 함께 따릅니다.
- 하위 프로젝트의 `AGENTS.md`가 있으면 해당 규칙을 우선합니다.
- TTS 또는 공개 데이터셋 기반 로컬 AI 작업 전에는 `Others/DOCS/TTS.md`를 읽습니다. 해당 문서는 참고용이며, 현재 상태는 실제 코드·메타데이터·README로 재확인합니다.

## 공통 원칙

- 각 하위 폴더를 독립 프로젝트로 취급하고, 코드·환경·모델·데이터 경로를 먼저 확인합니다.
- 모델, 데이터셋, 외부 도구의 버전·라이선스·배포 조건은 공식 출처에서 확인합니다.
- 로컬 전용 요청은 loopback 바인딩과 외부 공유 비활성화를 기본값으로 사용합니다.
- 대용량 다운로드·변환은 대상, 예상 용량, 저장 위치, 재개 방법, 현재 상태를 기록합니다.
- 사용자 작성 문서·목록·설정은 자동 생성 또는 일괄 재정렬 전에 사용자 파일로 간주하고 보존합니다.

## 데이터와 라이선스

- 상업 이용 가능 여부, 수정·재배포 조건, 출처 표시 의무를 분리해 기록합니다.
- 데이터셋 라이선스와 실제 사람의 음성·이미지·개인정보에 관한 권리는 별도로 검토합니다.
- `NC` 또는 조건이 불명확한 데이터는 상업 목적 환경에 추가하지 않습니다.
