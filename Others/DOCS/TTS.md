# 로컬 TTS 구축 참고

## 읽는 시점과 사실 확인 순서

공개 음성 데이터셋을 사용한 로컬 TTS 구축·수정·평가 작업 전에 읽습니다. 이 문서는 작업 규칙의 배경과 재발 방지 기준을 제공하며, 현재 상태는 아래 순서로 확인합니다.

```text
실행 코드·보이스팩 메타데이터·실제 파일 → 프로젝트 README → 이 문서
```

## 현재 Qwen3-TTS 운영 기준

- WebUI는 기본적으로 `127.0.0.1`에만 바인딩하고 외부 공유 링크를 사용하지 않습니다.
- 현재 Base 복제 경로는 `generate_voice_clone(text, language, ref_audio, ref_text)`를 사용합니다.
- Base 복제에는 자연어 `instruct`가 적용되지 않습니다. UI의 `지침(EN)`을 스타일 제어값으로 설명하지 않습니다.
- 지침 기반 스타일 제어는 CustomVoice 또는 VoiceDesign 모델·UI 연결을 별도 작업으로 구현하고 검증합니다.
- 결과·데모·포트 상태는 코드 실행 뒤 실제 파일과 로컬 연결로 확인합니다.

## 보이스팩 등록 기준

1. 공식 배포처에서 데이터셋의 상업 이용, 수정, 재배포, 출처 표시 조건을 확인합니다.
2. `pack.json`의 `commercial_use`가 JSON 불리언 `true`인지 확인합니다.
3. `reference.wav`, 비어 있지 않은 UTF-8 `reference.txt`, 필요한 `voice.json`을 확인합니다.
4. `reference.txt`는 참조 음성의 정확한 전사여야 합니다. 추정 전사는 검증 없이 등록하지 않습니다.
5. 데이터셋 라이선스와 별개로 화자 동의, 개인정보, 인격권, 퍼블리시티권, 실제 인물 오인 가능성을 검토합니다.

`NC` 또는 상업 이용 조건이 불명확한 데이터는 상업 목적 보이스팩에 추가하지 않습니다.

## 참조 음성 정제와 선별

목표는 단순한 노이즈 제거가 아니라 화자 특성을 훼손하지 않은 일관된 참조 음성입니다.

```text
원본 보존 → VAD → 약한 노이즈 억제 → 길이/클리핑/SNR 검사
→ 화자 군집화·이상치 제거 → 전사 대조 → 품질 점수와 사람 청취
```

- 원본 파일을 덮어쓰지 않고 정제 후보를 별도 보관합니다.
- 강한 노이즈 제거·음성 강화는 화자 음색을 바꿀 수 있으므로 자동 승인 기준으로 사용하지 않습니다.
- VAD, 화자 임베딩, ASR, 품질 점수 도구는 코드와 사전학습 가중치의 라이선스를 각각 확인합니다.

## 데모·다운로드·문서 운영

- 데모 비교에는 같은 언어·대본·평가 규격을 사용하고, `demo.wav` 존재·0바이트 여부·재생을 확인합니다.
- 남성/여성 등 메타데이터가 없으면 추정해 기록하지 않습니다.
- 대용량 다운로드는 하나의 실제 대상 파일에 하나의 다운로드 작업만 사용합니다. 예상 최종 크기와 부분 파일 크기로 진행률을 계산합니다.
- 직접 다운로드와 다중 연결 도구를 병행해 진행률을 혼동하지 않습니다.
- `README.md`는 현재 운영·라이선스 문서입니다. `Voices.md`는 사용자 작성 목록이므로 자동 재생성·정렬·열 변경·덮어쓰기를 금지합니다.
