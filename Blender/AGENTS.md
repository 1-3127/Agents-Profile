# Blender Agent Instructions

## 적용 범위

- 이 파일은 VSCode 루트 기준 `./Blender` 아래의 Blender 작업에 적용합니다.
- 루트 `AGENTS.md`와 `Agents/workflow.md`를 함께 따릅니다.
- 더 가까운 `AGENTS.md`가 있으면 그 규칙을 우선합니다.

## 작업 전 확인

- 대상 `.blend` 파일의 절대 경로와 Blender 버전
- 연결된 텍스처·캐시·외부 라이브러리의 위치
- 현재 파일의 저장 상태와 사용자가 열어 둔 Blender 세션
- 산출물 형식, 렌더 엔진, 해상도, 프레임 범위

경로나 버전, 렌더 설정을 추측하지 않습니다.

## 변경과 검증

- `.blend`는 바이너리 파일이므로 직접 텍스트 편집하지 않습니다.
- 사용자 파일을 덮어쓰지 않습니다. 별도 버전이 필요하면 사용자의 네이밍 규칙을 따르고, 없으면 작업 전 승인과 복구 방법을 확인합니다.
- Blender Python 자동화는 대상 파일·컬렉션·오브젝트를 명시적으로 지정하고, 성공 여부를 재조회 또는 저장 결과로 검증합니다.
- 장시간 렌더링·시뮬레이션은 시작 전 예상 산출물 경로와 영향 범위를 보고하고, 완료 후 출력 파일을 확인합니다.
- 외부 애드온, 스크립트, 에셋은 출처·라이선스·실행 권한을 확인한 뒤 사용합니다.
